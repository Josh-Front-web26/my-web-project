# Rationale

[my-web-project live link](https://josh-front-web26.github.io/my-web-project/)

The final design of the responsive website was quite successful. Using HTML5 and CSS, the high-fidelity prototypes were reflected in the final website. Feedback from the high-fidelity prototypes was implemented into the website. Changes from feedback, such as removing the unnecessary account page for users and changing the scale so important, like subscribing to the newsletter section by incorporating that into the footer. Feedback was useful in making any final adjustments to the final design. 

When looking back at the low-fidelity prototypes, the main aspects that were implemented were using card layouts and making the website image-focused. The current Canberra Modern website is cluttered, so using card layouts helped organise the content in a much clearer design. In the brief, they mention they wanted the website to be image and design driven, so using images to showcase the mid-century modern buildings was important. The high-fidelity prototype was kept relatively the same in terms of typeface, colour palette, and organisation. However, there was difficulty trying to include YouTube videos, animations, and image panels. 


The most difficult part of this project was using media queries, CSS grid layout, and flexbox. As it was important to use these for your website to adapt seamlessly to different screens, it was necessary to make sure all elements of each page adapted effectively. Each page has images, so it was difficult to manage the style.css, so the website isn’t completely perfect when adjusting to a smaller screen, unfortunately. Alignment with text and images needs improvement when looking at a smaller device, as it makes the site look visually inconsistent compared to a desktop screen size. Another challenge was CSS specificity, as it was sometimes difficult to reuse the same style or target individual elements for each page. It was confusing when styles that were added to the style.css file later were overridden and not visible when looking at the HTML page. Targeting HTML with specific classes and ID’s and following rules such as using only the same ID once on a page was overwhelming.


One of the strengths of the website is the responsive text and images. It was important that the clickable elements of each page responded to the user when hovering to ensure accessibility (Adobe, 2025). Colour changes, size, and shadows were added to the hover effect so users are indicated which links they can click on. The header and the buttons change colour and size, and the images use shadow and size to make the website responsive and more interactive.


Creating the HTML pages was definitely easier compared to the style.css sheet. Each page of the website has its own file, making it easier to edit the headings and paragraphs. The basic HTML5 document page was used as a starting point to set up the pages. Semantic tags really helped navigate the content by distinguishing headings, paragraphs, links, and images. Once all the content was placed in the file, GenAI helped further develop the style and layout. When unsure of how to create certain codes, using the browser to search for what Visual Studio Code can be used for certain styling, like the responsive links and image layouts. GitHub Copilot was used for suggestions and questions when certain elements were not displaying when opening the HTML files in the browser, and how to implement CSS grid and flexbox that would best work with the Canberra Modern images.


Visual Studio Vode and GitHub were not tools used previously. Learning the basics of how to use both platforms to be instantly productive using tools such as ghost text completion really made coding easier with its suggestions (Visual Studio Code, 2024). Beginner guides were useful in understanding that the workspace can display all your project files in a single interface and move between different pages quickly (Mikey No Code, 2026). While creating the site, a reset.css file, also known as a reset stylesheet, was made to reduce styling inconsistencies throughout all browsers (A & S.Meyer, 2019). The search bar tool was also efficient in locating and replacing any words when sorting, especially navigating the long cascading style sheet (Coder Coder, 2025). Beginner-friendly videos and sites guided the process and helped create the final responsive website.
